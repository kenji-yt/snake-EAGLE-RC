The 'DNA' directory is a template showing the structure and directory names that a snake-EAGLE-RC input directory should have. IT IS NOT a test dataset! The files inside are empty and just serve to illustrate what the content should be. You must change the names of the polyploids subdirectories ('sample_1, sample_2, sample_3') and of the subgenome directories ('subgenome_A, subgenome_B') to match those of your data. If your data is WGBS or RNA, change the name of the 'DNA' directory to 'WGBS' or 'RNA'.
